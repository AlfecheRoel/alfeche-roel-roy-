ORBIT CHAT — GREEN / BLACK RGB EDITION (v1.4.0)

INSTALL
1. Extract this ZIP file.
2. Open Google Chrome and visit chrome://extensions
3. Enable Developer mode.
4. Click Load unpacked and select the extracted ext-chrome folder (the folder containing manifest.json).
5. Refresh the website tab and click the Orbit logo button.

WHAT'S INCLUDED
- Premium black + neon green animated RGB border and custom Orbit SVG logo
- Responsive floating chat window and locally saved chat history
- Chat with local quick replies for greetings, help, date/time, and simple arithmetic
- Groups category: create and delete your own groups, with optional descriptions
- Saved category: add links, notes, ideas, resources, study/work references; open saved web links and delete items
- Tools category: calculator, length/weight/temperature converter, stopwatch, countdown, auto-saved notes, RGB color picker, and password generator
- YouTube links render an inline embedded player in chat; dropped YouTube links are added automatically
- YouTube videos do not autoplay; press Play in the embedded player
- Other links remain plain text for safety
- Data for chat, groups, saved items, and notes is stored locally on this browser/device

LIMITATIONS
- This is a local browser extension, not a multi-user messaging service.
- Open-ended AI replies require an AI service/API connection. No API key or server is included.
- Groups are personal organizational labels; they do not invite or message other users.
- Saved links open in a new tab only when you click Open link.

PRIVACY
The extension does not send chat messages, groups, saved items, or notes to a server. Use local storage only for information you are comfortable keeping on this device.
